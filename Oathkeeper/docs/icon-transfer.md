# High-resolution portable app icon transfers

This repository includes ten independent files `web/public/art/store-icons/transfer-NN.svg`, one for every approved alternate icon (01, 02, 04, 05, 06, 07, 08, 11, 12, 14).

Each SVG is a **self-contained code wrapper** around the original **1254×1254 WebP** master. The complete original WebP bytes are embedded as a base64 `data:image/webp` URI inside an SVG `<image>` element. Nothing is cropped, redrawn, recompressed or upscaled. **They are not true vector drawings**; SVG is only the portable code-based container.

## How to use

- View or download an individual file: `web/public/art/store-icons/transfer-01.svg` (substitute the two-digit identifier).
- Web use: `<img src="/art/store-icons/transfer-01.svg" alt="Moonlit Citadel">`.
- JavaScript: import `SELECTED_APP_ICONS` from `web/store-icon-catalog.js`, then read `portableSvgPath`.
- Regenerate all ten after editing a master: `python3 scripts/export_portable_icons.py` from `Oathkeeper/`.
- Verify exact embedded bytes: `node --test tests/portable-icons.test.mjs`.
- **Android / iOS launcher icons:** do not use these SVG containers directly. Keep using the native adaptive layers and Apple icon resources generated by `scripts/generate-free-icons.py`. Native launcher appearance depends on mask, padding and launcher caching.

## Known screenshot-to-source artwork mismatch (2026-11-11)

The supplied screenshot shows D20 before battleaxes. The repository's file `icon-07.webp` actually depicts battleaxes and `icon-08.webp` depicts a D20, while catalog names are reversed. `icon-11.webp` also depicts a crystal castle rather than the three prominent purple crystals in the supplied screenshot. These portable files **faithfully preserve the existing source files**. They cannot be certified as pixel-identical to the screenshot artwork. The mistaken source/art selection and native launcher parity must be repaired separately, against the original approved image masters. Merely packaging existing artwork in SVG will not resolve the mismatch.
